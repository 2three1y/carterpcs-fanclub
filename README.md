# The Official CarterPCs Fan Club

An RGB-maxed, fully accessible fan club website for tech creator CarterPCs, with a benchmark-style fan counter that never stops climbing.

**Live demo:** https://2three1y.github.io/carterpcs-fanclub/

## Features

- Breaking-news ticker
- Ever-rising fan counter styled like a benchmark readout
- CarterPCs Facts
- Benchmarks joke section
- Fake fan reviews
- RGB Founders Edition membership card with confetti join
- "Overclock the hype" button

## Accessibility

- Skip link straight to the main content
- Fully keyboard operable, with a clearly visible focus ring
- Pause button that stops all motion (ticker, counter animation, confetti)
- Respects `prefers-reduced-motion`
- Screen-reader-friendly fan counter and news ticker (no announcement spam)
- Semantic HTML and high-contrast colors

## Run it locally

It's a plain static site: no build step, no dependencies. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
